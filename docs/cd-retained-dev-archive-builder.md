# Retained-dev archive builder (offline steppingstone)

Status: local deterministic build only. No AWS, credentials, network, MAPIT
session, private ledger, or workflow operation is performed.

`scripts/build_aws_retained_dev_archive.py` is separate from the historical
`build_aws_dev_runtime.py` builder. It reuses only that module's pure locked
wheel inventory, wheel unpacking, source allowlist, bounded file, and
deterministic ZIP helpers. It does not modify or parameterize the historical
builder.

Inputs are explicit local paths for the pinned ARM wheel directory, public
JWKS snapshot, and create-only output path, plus a validated source SHA-1,
10-character API id, and explicit JWKS SHA-256. The policy is fixed through
`cognito_dev_policy` using the retained synthetic pool/client/owner constants.
The archive contains:

- the historical fixed source allowlist and pinned wheel inventory;
- `cognito-public-jwks.json` and its public digest manifest;
- `retained-dev.manifest.json`, generated by
  `build_retained_dev_manifest` with the source/API/JWKS bindings and bounded
  synthetic execution window.

ZIP ordering, timestamps, permissions, compression, entry limits, total
uncompressed bytes, and compressed size are deterministic and bounded. The
summary includes an immutable `RetainedDevBuildReceipt` sealed by this builder.
It binds the archive SHA-256 to source-allowlist, source-content, wheel-lock,
wheel-content, manifest, JWKS, API, and bounded execution-window metadata.
The publisher accepts that receipt rather than untrusted individual source or
manifest fields; a ZIP with a copied manifest but different contents fails its
archive digest check. Receipt objects are integrity evidence inside this
offline pipeline, not a cryptographic trust boundary against arbitrary code
in the same Python process. Output is create-only and cannot replace an
existing file.

This builder produces a synthetic closed runtime candidate. It does not prove
CloudFormation, S3, IAM, role association, artifact ownership, or deployment
acceptance.
